# 「秒跳」产品需求文档 v0.2

> 一句话：不 root、不联网、纯本地的 Android 工具——自动点掉开屏广告的「跳过」，并在被广告「摇一摇」带到浏览器 / 应用商店时自动退回。

| 项 | 内容 |
|---|---|
| 产品名 | 秒跳（工作名，可改） |
| 包名 | `com.miaotiao.adskip` |
| 版本 | v0.2（MVP + 红果专属自动化） |
| 日期 | 2026-11-11 |
| 平台 | Android 11+（`minSdk 30`，`targetSdk 34`） |
| 分发 | 侧载自用，不做商店合规 |
| 目标设备 | 努比亚 Z50 Ultra（MyOS 13/14）；联想小新 Pad Pro 2021（Android 11/12） |
| 设计参照 | 截图 App 的页面结构与信息层级 |

---

## 1. 背景与目标

### 1.1 背景

- 国内主流 App 开屏普遍接入 3~5 秒广告，且按钮小、倒计时长。
- 部分广告用「摇一摇」触发 deeplink，走路、手抖就会跳到浏览器 / 电商 App，还要手动返回。
- 系统没有原生能力解决，只能靠无障碍服务读屏 + 模拟点击。

### 1.2 可量化目标

| 指标 | 目标 |
|---|---|
| 开屏跳过成功率（Top 20 常用 App × 20 次） | ≥ 80% |
| 跳过按钮出现 → 点击完成 | ≤ 1.5s |
| 摇一摇误拦截率（人工抽查 100 次正常跳转） | ≤ 1% |
| 服务断开 → 用户收到提示 | ≤ 30s |
| 常驻耗电 | ≤ 2%/h（亮屏使用） |
| 冷启动到首页可操作 | ≤ 1.5s |

### 1.3 非目标（v0.1 明确不做）

- hosts / VPN 级去广告
- root / Xposed / LSPosed 方案
- 云端规则热更新、账号体系
- iOS 端
- 浏览器内广告拦截

## 2. 用户与场景

| 场景 | 描述 | 期望 |
|---|---|---|
| A. 打开 App | 点开淘宝 / 贴吧 / 番茄，先看 3~5 秒开屏广告 | 无感，直接进内容 |
| B. 摇一摇误触 | 走路或手抖触发广告摇一摇，跳到浏览器 / 应用商店 | 自动退回原 App，别让我手动返回 |
| C. 个别 App 不想处理 | 某些 App 的「跳过」点了反而误触，或游戏内广告影响操作 | 能加入排除列表 |
| D. 服务被系统清理 | MyOS / ZUI 后台清理后无障碍失效，自己不知道 | 能及时发现并一键恢复 |
| E. 换机 / 平板 | 小新 Pad Pro 横屏、分屏使用 | 布局正常，事件不串 |

用户只有一个人：开发者本人（自用），所以不做多用户、不做引导教程的长流程。

## 3. 产品范围

### 3.1 MVP（v0.1）

1. 无障碍服务状态卡 + 跳转设置
2. 自动跳过开屏广告（关键词 + 常见 SDK 规则 + 手势兜底）
3. 摇一摇跳转拦截（目标包名集合 + 时间窗启发式）
4. 四个功能开关（跳过 / 拦截 / 振动 / 自动恢复）
5. 统计：今日跳过、累计跳过、拦截跳转
6. 不处理的 App 列表
7. 最近记录（200 条环形）
8. 前台服务保活 + 断连通知
9. 专属自动化：红果短剧「广告倒计时结束自动上滑」（详见 `docs/feature-hongguo-autoswipe.md`）

### 3.2 后续版本

| 版本 | 内容 |
|---|---|
| v0.2 | 规则 JSON 导入 / 导出、自定义规则、抓取节点树辅助补规则 |
| v0.3 | adb 授权 `WRITE_SECURE_SETTINGS` 后真正自动恢复无障碍 |
| v0.4 | 平板横屏 / 分屏专门适配、深色模式细节打磨 |
| v1.0 | 规则云端订阅（可选）、更多 ROM 保活模板 |

### 3.3 降级说明（重要）

「被系统关闭时自动恢复」在 v0.1 **只做断连检测 + 通知 + 一键跳转**，不做静默自动开启。
原因：Android 不允许普通 App 自行重新开启无障碍服务。截图 App 若能在无 adb 的情况下自动恢复，依赖的是特定 ROM 保活机制，需在 Z50 Ultra 上实测后再决定 v0.3 方案。

## 4. 信息架构

单 Activity + Compose，页面之间用状态切换（页面少，不引入复杂路由）。

| 页面 | 标识 | 说明 | 优先级 |
|---|---|---|---|
| 首页 | `home` | 状态卡 + 开关 + 统计 + 排除入口 + 记录 | P0 |
| 首次引导 | `guide`（底部弹窗） | 解释为什么需要无障碍 + 去开启 | P0 |
| 选择应用 | `appPicker` | 搜索、多选、保存排除列表 | P1 |
| 关于 | `about` | 版本、规则版本、开源许可 | P2 |

导航关系：

```
首页 ──点击「+ 添加」/ 排除卡──▶ 选择应用 ──保存──▶ 首页
  │
  ├── 首次启动自动弹出「首次引导」
  └── 点击「无障碍设置」──▶ 系统设置 ──返回──▶ 首页（刷新状态）
```

## 5. 页面详细设计

### 5.1 首页

#### 布局（自上而下，页面左右边距 16dp，卡片间距 12dp）

1. 顶部说明（两行内）：`开屏广告自动跳过 · 摇一摇误触自动返回`
2. 服务状态卡
3. 功能开关卡（4 行）
4. 统计卡（3 列）
5. 排除列表卡
6. 最近记录卡

> 注：功能开关卡下方还有一张「专属功能」卡（红果短剧 · 倒计时结束自动上滑），规格见 `docs/feature-hongguo-autoswipe.md`。

#### 5.1.1 服务状态卡

| 元素 | 规格 |
|---|---|
| 状态点 | 8dp 圆点：运行中 `#22C55E`，未开启 `#9CA3AF` |
| 标题 | 17sp Medium，`#16181D` |
| 状态胶囊 | 已开启：背景 `#E8F6EE` / 文字 `#15803D`；未开启：背景 `#F1F2F4` / 文字 `#6B7280`；圆角 999dp |
| 说明文字 | 13sp，`#6B7280`，最多两行 |
| 主按钮 | 高 48dp，圆角 14dp，填充 `#2E6BFF`，白字 16sp Medium |
| 次按钮 | 同高，背景 `#F1F2F5`，文字 `#16181D` |

状态与文案：

| 服务状态 | 圆点 | 胶囊 | 说明文案 |
|---|---|---|---|
| 运行中 | 绿 | 已开启 | 正在运行。若发现失效，请确认 MyOS 没有把它从后台清理掉。 |
| 未开启 | 灰 | 未开启 | 尚未开启，开启后才能自动跳过广告。 |
| 已断开 | 灰 | 已断开 | 服务被系统清理了，点下方按钮重新开启。 |

按钮行为：

- **无障碍设置** → `ACTION_ACCESSIBILITY_SETTINGS`，优先直达本 App 的服务详情页（部分 ROM 支持 `ACTION_ACCESSIBILITY_DETAILS_SETTINGS`），失败则落到列表页。
- **后台运行** → 依次尝试：电池优化白名单申请 → 应用详情页 → 厂商自启动管理页（MyOS 路径），全部失败则打开应用详情页。

刷新时机：`onResume` + 服务连接 / 断开回调 + 每 5s 轮询一次（仅首页可见时）。

#### 5.1.2 功能开关卡

| 开关 | 标题 | 副标题 | 默认 |
|---|---|---|---|
| `autoSkip` | 自动跳过开屏广告 | 识别「跳过 / 关闭广告」按钮并点击 | 开 |
| `interceptJump` | 拦截摇一摇跳转 | 被广告摇到浏览器 / 商城时自动返回 | 开 |
| `vibrate` | 操作时轻微振动 | 跳过或拦截成功时提示一下 | 开 |
| `autoRestore` | 被系统关闭时自动恢复 | 系统清理后自动把无障碍改回开启 | 开 |

- 交互：点击整行或开关均可切换，写入 DataStore，服务侧读同一份配置，**即时生效**（不重启服务）。
- 振动：`Vibrator` 30ms，`VibrationEffect.createOneShot`。
- `autoRestore` 在 v0.1 的实际行为 = 检测断开 → 发通知 + 首页红点提醒；文案里加一个「?」图标说明限制（点击弹半屏说明）。

#### 5.1.3 统计卡

| 元素 | 规格 |
|---|---|
| 数字 | 28sp Bold，`#16181D`，等宽数字 |
| 标签 | 13sp，`#6B7280` |
| 三列 | 今日跳过 / 累计跳过 / 拦截跳转 |

口径见第 9 节。数字变化时做 150ms 数字滚动动画（可选，P2）。

#### 5.1.4 排除列表卡

| 元素 | 规格 |
|---|---|
| 标题 | 17sp Medium「不处理的 App」 |
| 右侧操作 | 「+ 添加」16sp `#2E6BFF` |
| 说明 | 13sp「列表里的应用不会被自动跳过或拦截」 |
| 空态 | 13sp `#9CA3AF`「暂无，默认处理所有应用」 |
| 非空态 | 显示前 3 个 App 图标（24dp）+ 名称，超出显示「等 N 个」 |

交互：点「添加」或整卡 → 选择应用页。

#### 5.1.5 最近记录卡

| 元素 | 规格 |
|---|---|
| 标题 | 17sp Medium「最近记录」 |
| 右侧操作 | 「抓取」16sp `#2E6BFF`；「清空」16sp `#9CA3AF` |
| 记录行 | 时间（13sp，`#9CA3AF`，等宽）+ 应用名（14sp，`#16181D`）+ 动作标签（13sp） |
| 动作标签 | 跳过广告 `#2E6BFF`；拦截跳转 `#F59E0B` |
| 空态 | 「还没有记录，去打开一个 App 试试」 |
| 最多展示 | 最近 20 条，其余不展示 |

- **抓取**（v0.1 定义）：抓取当前前台界面的无障碍节点树（包名、类名、文本、contentDescription、viewId、bounds），格式化为文本复制到剪贴板，Toast「已复制当前界面信息」。用于补规则、排查问题。若判定不方便，可改为「导出最近记录」。
- **清空**：二次确认对话框，确认后清空记录与计数？——只清记录，不动统计。
- 记录行点击：复制该行完整信息（P2）。

### 5.2 首次引导（底部弹窗）

触发：首次启动且无障碍未开启，首页加载完成后弹出。

| 元素 | 内容 |
|---|---|
| 标题 | 开启无障碍，才能自动跳过 |
| 说明 1 | 只读取当前界面的文字和按钮，用来找到「跳过」 |
| 说明 2 | 不联网、不上传任何屏幕内容 |
| 说明 3 | 随时可以在系统设置里关闭 |
| 主按钮 | 去开启 |
| 次按钮 | 稍后 |

- 「去开启」→ 系统无障碍设置；用户返回 App 后自动检测，成功 Toast「服务已就绪」。
- 「稍后」→ 关闭弹窗，首页状态卡保持未开启；下次启动不再弹（用 `guideShown` 标记），只保留状态卡入口。

### 5.3 选择应用

| 元素 | 规格 |
|---|---|
| 顶部 | 返回箭头 + 标题「选择应用」 |
| 搜索框 | 圆角 12dp，占位「搜索应用名或包名」 |
| 列表项 | 图标 40dp + 名称 15sp + 包名 12sp 灰 + 右侧复选框 |
| 底部栏 | 固定，左侧「已选 N 个」，右侧「保存」主按钮 |
| 排序 | 已选在前，其余按名称拼音排序 |

- 应用列表来源：`PackageManager.getInstalledApplications`，需要 `QUERY_ALL_PACKAGES`（自用无合规压力）。
- 加载中显示 skeleton；无匹配显示空态。
- 保存后返回首页，排除卡显示数量。
- 已选中的应用即使开启「自动跳过」也不处理。

### 5.4 关于（P2，可先占位）

版本号、规则版本、开源许可、反馈入口（复制邮箱 / 日志路径）。

## 6. 核心流程

### 6.1 首次使用

```
启动 → 首页 → 无障碍未开启 → 弹「首次引导」
  → 去开启 → 系统设置 → 开启服务 → 返回
  → onResume 检测到已连接 → 绿点 + Toast「服务已就绪」→ 引导完成
```

### 6.2 打开 App 触发跳过

```
用户点开 App
  → 系统发 TYPE_WINDOW_STATE_CHANGED（包名 = 目标 App）
  → 服务判断：开关开？包名不在排除列表？启动后 8s 内？
  → 延迟 300ms 扫描活动窗口节点树
  → 命中「跳过 / 关闭 / Skip / 倒计时」→ ACTION_CLICK
  → 失败则 GestureDescription 点坐标
  → 成功：+1 今日、+1 累计、写记录、振动（可选）
  → 未命中：再重试 2 次（600ms / 1200ms）
```

### 6.3 摇一摇拦截

```
前台包名变化：AppA → 浏览器 / 应用商店
  → 判定：开关开？AppA 不在排除列表？切换发生在 AppA 启动后 8s 内？
  → 是：performGlobalAction(GLOBAL_ACTION_BACK)
  → 成功：+1 拦截、写记录、振动
  → 防循环：同一目标包 1s 内只回退一次，回退后 2s 内不再触发
```

### 6.4 服务断开

```
系统关闭无障碍 / 服务进程被杀
  → onUnbind / onInterrupt 回调
  → 更新状态为「已断开」→ 发送通知「无障碍服务已断开，点击恢复」
  → 首页红点 + 状态卡文案切换
  → 用户点通知 → 直达设置页
```

## 7. 状态机

```
UNKNOWN ──检测──▶ DISABLED ──用户开启──▶ ENABLED
                    ▲                      │
                    │                      │ 被系统关闭
                    └────── BROKEN ◀───────┘
```

| 状态 | 判定依据 | UI |
|---|---|---|
| UNKNOWN | 尚未检测 | 灰点，短暂 loading |
| DISABLED | 未在 `ENABLED_ACCESSIBILITY_SERVICES` 中 | 灰点 + 未开启 |
| ENABLED | 已在列表且 `onServiceConnected` 过 | 绿点 + 已开启 |
| BROKEN | 曾 ENABLED，之后 `onUnbind` 或检查不到 | 灰点 + 已断开 + 通知 |

## 8. 数据模型

### 8.1 设置（DataStore Preferences）

| key | 类型 | 默认 | 说明 |
|---|---|---|---|
| `auto_skip` | Boolean | true | 自动跳过开关 |
| `intercept_jump` | Boolean | true | 拦截跳转开关 |
| `vibrate` | Boolean | true | 振动开关 |
| `auto_restore` | Boolean | true | 自动恢复开关 |
| `excluded_packages` | StringSet | empty | 排除的应用包名 |
| `guide_shown` | Boolean | false | 首次引导是否已弹过 |
| `skip_delay_ms` | Int | 300 | 首次扫描延迟（高级设置，P2） |
| `max_retry` | Int | 2 | 重试次数（P2） |

### 8.2 统计（DataStore）

| key | 类型 | 说明 |
|---|---|---|
| `today_skipped` | Int | 今日跳过数 |
| `today_epoch_day` | Long | 今日对应的 epochDay，跨天时归零 |
| `total_skipped` | Long | 累计跳过 |
| `total_intercepted` | Long | 累计拦截 |

### 8.3 记录（Room 或 JSON 文件，v0.1 建议 JSON 文件最简单）

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | Long | 自增 |
| `timestamp` | Long | 毫秒时间戳 |
| `packageName` | String | 触发应用包名 |
| `appLabel` | String | 应用显示名（缓存，取不到用包名） |
| `type` | Enum | `SKIP` / `INTERCEPT` |
| `detail` | String? | 命中的按钮文案 / 目标包名 |

- 最多保留 200 条，超出删最旧。
- 写入频率低（每次跳过一条），直接用 `synchronized` + 文件追加即可，v0.2 再考虑 Room。

### 8.4 排除列表

- 存 `StringSet`，读写时注意 DataStore 的 Set 不可变，需复制。
- 服务侧每次事件读一次（内存缓存 + Flow 收集，避免高频 IO）。

## 9. 统计口径

| 指标 | 定义 |
|---|---|
| 今日跳过 | 本地时区当天 00:00 起，成功点击跳过的次数；同一窗口重复点击只计 1 次 |
| 累计跳过 | 安装以来累计，不做云同步，卸载归零 |
| 拦截跳转 | 成功执行返回操作并回到原 App 的次数；同一目标包 1s 内多次触发只计 1 次 |
| 跨天 | 每次写入前比较 `epochDay`，不同则今日清零 |

## 10. 文案规范

- 中文为主，不用感叹号堆砌，语气克制。
- 数字与单位间不加空格（3 秒、8 秒）。
- 按钮动词开头：开启、添加、保存、清空。
- 状态描述用陈述句，不用「亲」「哦」等口语。

Toast / 通知文案：

| 场景 | 文案 |
|---|---|
| 服务就绪 | 服务已就绪 |
| 跳过成功 | （不发通知，仅振动） |
| 服务断开通知 | 无障碍服务已断开，点击恢复 |
| 抓取成功 | 已复制当前界面信息 |
| 清空确认 | 清空后无法恢复，确定清空？ |
| 保存排除 | 已保存 |

## 11. 异常与边界

| 场景 | 处理 |
|---|---|
| 节点树为空 / 拿不到根节点 | 跳过本次，不报错；记录 debug 日志 |
| 多窗口 / 分屏 | 只处理 `getWindows()` 中 `isActive` 的窗口；平板横屏重点测 |
| 横屏 | 布局用 `WindowSizeClass` 分支，卡片最大宽度 640dp 居中 |
| 深色模式 | 跟随系统，卡片用 `surfaceVariant` 系 |
| 点击无效 | 重试 1 次后改用坐标点击；再失败放弃 |
| 连续弹广告（切多个页面） | 每个新窗口独立判断，但同一包 1s 内最多点 2 次 |
| 系统权限弹窗 | 不在处理范围，跳过 |
| 广告 WebView 无节点 | 记录未命中，交给人补规则；v0.2 用抓取工具辅助 |
| 无障碍服务崩溃 | 前台服务持通知存活，`onServiceConnected` 重建 |
| 平板 Dock / 分屏切换 | 拦截逻辑需排除「多任务界面」包名，避免误回退 |
